# [Department Name] — Processes

Repeatable workflows and SOPs for this department.

## Which template to use?

| Template | Use when |
|----------|----------|
| `process-template.md` | Standard process — sequential steps with clear inputs/outputs. Use for onboarding, hiring, approvals, recurring tasks. |
| `runbook-template.md` | Operational runbook — a process that can fail in specific ways, requires diagnosis, and has known gaps. Use for pipelines, integrations, batch jobs, delivery processes. |

**Rule of thumb:** if the process has a "Failure Modes" table, use `runbook-template.md`. Otherwise, use `process-template.md`.

## How to Add a Process

1. Copy the appropriate template and rename it: `1-settlement.md`, `2-onboarding.md`, etc.
2. Fill in all sections — leave no placeholder empty before setting `data_status: verified`.
3. Add an entry to the Index table below.
